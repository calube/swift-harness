# Example queue

## Problem

Guests lose their cart when offline.

## Requirements

- req-orders-survive-restart: A queued order survives an app restart.
- req-orders-drain-on-reconnect: Queued orders submit once the network returns.

## Decision

Persist the queue to disk.

## Risks

- Disk full.
